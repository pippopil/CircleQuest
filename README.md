# CircleQuest (КругоКвест) 🌿

> Безопасное кроссплатформенное мобильное приложение для подростков и молодежи до 18 лет: совместные реальные офлайн-квесты в закрытых кругах близких друзей без лайков, рейтингов и давления соцсетей.

---

## 🌟 Ключевая концепция

Современные соцсети перегружены публичными счетчиками подписчиков, алгоритмами удержания внимания и давлением идеальных фотографий. **CircleQuest** предлагает альтернативу:

1. **Закрытые «Круги» (до 10 человек)**: Никаких открытых профилей, поиска по имени и публичных лент. Только близкие друзья из реальной жизни.
2. **Командный успех вместо конкуренции**: Общий недельный прогресс-бар круга. Личные достижения видны только как общий вклад, без токсичных лидербордов.
3. **Реальные действия в офлайне**: Квесты переносят активность из экрана в реальный мир — спорт, помощь животным, экология и забота о районе.
4. **Система «Искры» (Анти-лайки)**: Эмоциональная поддержка через предустановленные стикеры с мягким акустическим сопровождением (Web Audio API) без публичных счетчиков популярности.
5. **Безопасность и защита несовершеннолетних (COPPA / GDPR / 152-ФЗ)**:
   - Проверка возраста и верифицируемое согласие родителей для участников младше 14 лет.
   - Двухкликовая форма «Пожаловаться» на любой отчет или участника.
   - Панель модератора с историей действий и системой апелляций.
   - Автоматический фильтр контента и строгое правило «Без лиц на фотоотчетах» ради приватности.
   - Бережные уведомления с защитой учебных часов (08:30–14:30) и сна (22:00–07:30).

## 📲 Android Бета-тестирование (Сборка #101, v1.0.0-beta.1)

Приложение оптимизировано для работы на смартфонах под управлением **Android** с поддержкой стандартов **PWA (Progressive Web App)** и оффлайн-кэшированием:

1. Откройте приложение в браузере **Google Chrome** или **Яндекс** на смартфоне Android.
2. В появившемся баннере нажмите кнопку **«Установить»** (либо откройте меню браузера `⋮` и выберите **«Установить приложение»** / **«Добавить на главный экран»**).
3. Приложение установится на домашний экран устройства с иконкой 🌿 и запускается как нативное полноэкранное приложение без адресной строки.
4. Доступен оффлайн-режим через Service Worker: квесты, карта и прогресс кэшируются локально.

## 🚀 Основной стек технологий

- **Фронтенд**: React 19, TypeScript, Vite, Tailwind CSS v4, Motion
- **Иконки**: Lucide React
- **Звуковой движок**: Web Audio API (генерация пентатонических аккордов и колокольчиков без внешних MP3)
- **Хранилище данных**: Реактивное состояние с локальной персистентностью (`localStorage`)
- **Архитектура**: Mobile-First SPA с адаптацией под любые экраны и touch-эргономикой ($\ge 44\text{px}$)

## 📱 Ключевые экраны и разделы

- **Квесты недели**:
  - `Синхрон`: утренняя разминка 15–20 мин в один день с друзьями.
  - `Твори добро`: подкормка птиц, сбор пластика/батареек с фотоотчетом (без лиц).
  - `Детокс`: интерактивный фокус-таймер (15/30/45 мин) с дыхательной анимацией.
- **Наш Круг**:
  - Состав участников, передача прав создателя, инвайт-код и QR-код.
  - Лента личных Искр поддержки со звуковым воспроизведением.
- **Офлайн-карта района**:
  - Интерактивная векторная карта с точками сбора вторсырья, воркаут-площадками, книгообменниками и парковыми кормушками.
- **Профиль и Безопасность**:
  - Настройка аватара-символа, интересов, возраста, родительского согласия, сессий и DND-расписания.
- **Консоль модератора (Admin MVP)**:
  - Очередь жалоб, скрытие контента, предупреждения и рассмотрение апелляций.
